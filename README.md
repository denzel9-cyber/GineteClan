# Ginete Clan

The Ginete clan's habit, workout, challenge and chat app.

**Install it:** https://denzel9-cyber.github.io/GineteClan/

- **Android (Chrome):** open the link → **Install the app** (or ⋮ → *Install app*).
- **iPhone (Safari):** open the link → **Share** → **Add to Home Screen**.
- **Computer (Chrome/Edge):** open the link → **Install the app**.

The installed app opens the live Ginete Clan (a private Claude artifact), so everyone shares the same chat, levels and challenges, and new versions arrive automatically. Sign in to Claude with the account DG shared the app with.

This repository only holds the installable launcher (page, icons, manifest, service worker). The app itself is updated by publishing the Claude artifact.
